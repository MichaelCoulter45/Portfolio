# Michael Coulter Portfolio

The source for my personal portfolio site. It introduces my background, links to my work, and highlights the kinds of problems I enjoy solving: desktop automation, computer vision, and practical data tools.

## Featured work

- **JARVIS Assistant** — a Windows command-line prototype that parses a command, finds an application, and dispatches an action.
- **TypeKnight Auto Typer** — an experimental OCR and input-automation pipeline for reading on-screen prompts in real time.
- **Rock Paper Scissors Simulator** — a small browser project built with HTML, CSS, and JavaScript.

## Built with

HTML, CSS, JavaScript, and Bootstrap. The site also uses Google Fonts and is designed as a static site, so it can be deployed with GitHub Pages.

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Site structure

- `index.html` — landing page
- `projects.html` — project showcase and demo viewer
- `about.html` — background and technical interests
- `contact.html` — ways to connect
- `videos/` — locally hosted project demos

## Notes

This portfolio intentionally features projects I can explain in detail, including the problem each one addresses, its design, and its current limitations.
